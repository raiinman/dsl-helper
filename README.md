# DSL-Helper

Dead Signal Library - Helper, by Dead Signal Interactive.

[Website](https://raiinman.github.io/dsl-helper/) · [Updates](https://raiinman.github.io/dsl-helper/updates/) · [Support](https://raiinman.github.io/dsl-helper/support/) · [Privacy](https://raiinman.github.io/dsl-helper/privacy/) · [Terms](https://raiinman.github.io/dsl-helper/terms/)

DSL-Helper brings 137 bundled specialist guides into ChatGPT and Codex, with version-pinned online retrieval and an explicit bundled-only mode.

Support: michael@deadsignal.studio.

This repository hosts the static information pages. The plugin is being prepared for public directory review; hosting these pages does not mean OpenAI has approved the plugin.

Future versions and download information appear on the stable Updates page. No automatic-update behavior is implied.

## Maintaining the pages

Edit the HTML files, keep navigation relative, and commit to main. GitHub Pages publishes from the repository root. Keep .nojekyll in place. No build tools or runtime dependencies are required.

Imported workflow sources retain their original licenses and provenance; this repository does not grant a blanket license to the plugin bundle.
